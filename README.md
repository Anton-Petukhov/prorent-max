# ProRent MAX

Портфель коммерческой аренды: общая, вакантная, коммерческая и складская площадь, машина времени, разбор PDF и 3D-планы.

```bash
npm install
npm run dev
```

## Версии

Живой сайт — ветка `main`. Каждая устойчивая точка подписана меткой: к ней можно вернуться и с неё снова уйти вперёд на `main`.

| Метка | Ветка отката | Что внутри |
| --- | --- | --- |
| `v1-europe` | — | Европейская книга, машина времени, PDF и 3D-редактор |
| `v2-irkutsk` | `restore/before-electron` | Пионер, Брэнд Холл и шахматка |
| `v3-electron` | `restore/before-scheme-history` | ТЦ «Электрон» с плавающими подписями |
| `v4-scheme-history` | — | История схем Брэнд Холла (15 листов, 2023–2026) и Электрона (17 листов, 2022–2026) в объекте и в общей статистике |

Откат на предыдущую точку не удаляет более новую: `main` остаётся, пока её явно не переключат.
