# ProRent MAX — модуль «Прорент Анализатор» (MVP v1)

## Уже реализовано

- Новый маршрут /analyzer и пункт «Сверка» в меню.
- Две версии: «Архив / Базовая версия» и «Актуальная версия».
- Импорт XLSX, CSV, TSV, TXT, PDF с текстовым слоем.
- Встроенные исторические схемы «Брэнд Холла» и «Электрона», фиксированная схема «Пионера».
- Сверка по объекту, этажу и номеру; номера 1.01 и 101 не приравниваются.
- Различия по площади (порог 0,05 м²), статусу, добавленные и исчезнувшие номера.
- Предупреждения о дубликатах, пустой площади и неопределённом статусе.
- Поиск, фильтры, экспорт CSV, локальная история помещения и переносимый архив JSON.

## Ограничения

- Нет корпоративного API и OCR скриншотов до отдельного согласованного подключения.
- Сканированные PDF не извлекаются автоматически.
- Браузерный localStorage не является надёжным центральным архивом. Экспортируйте JSON.
- Схемы из MAX — демонстрационные/исторические данные, не подтверждение текущей вакантности.
- Переезды номеров не устанавливаются автоматически. Исчезновение и появление может означать переименование.
- Дубли совпадающих ключей не объединяются: первую строку берём для сравнения, остальные показываем как риск ошибки.

## Что запросить у службы поддержки для API

Просьба предоставить документацию и тестовый доступ с правами только на чтение, чтобы сверять помещения и их изменения.

1. Перечень объектов с постоянным ID, названием, адресом.
2. Помещения: постоянный premise_id, ID объекта, этаж, отображаемый номер, площадь и единицы измерения.
3. Статус (вакантно, занято, бронь), дата актуальности, дата начала действия.
4. Историю смены номера, площади и статуса с датами.
5. Фильтр по объекту и дате, пагинацию, форматы выгрузки, таймзону.
6. Тип авторизации, права (scopes), лимиты вызовов, срок действия токенов.
7. Тестовый контур, документацию, обезличенные примеры ответов и ошибки.
8. Условия хранения локальной копии данных и право доступа сотрудников.

Ключи и токены не нужно отправлять в чате. Будущий вызов API должен идти через защищённый серверный слой, а не напрямую из браузера.
